iTasks Manager - Sistema de Gestão Kanban 

O iTasks Manager é uma aplicação de gestão de tarefas baseada na metodologia Kanban. O sistema foi desenvolvido com React e Vite, permitindo a organização e persistência de fluxos de trabalho em diferentes estados de execução.

Funcionalidades principais
Quadro Kanban: Organização de tarefas em colunas estruturadas (Pendente, Em Curso, Concluído).

Gestão de Tarefas: Sistema de criação e edição de tarefas com títulos personalizados.

Persistência de Dados: Integração com localStorage via storage-mock.js, garantindo a manutenção dos dados após o encerramento da sessão ou atualização do navegador.

Interface: Design focado em usabilidade e responsividade.

Tecnologias Utilizadas
React: Biblioteca para construção da interface.

Vite: Ferramenta de build e automação de desenvolvimento.

Lucide React: Conjunto de ícones vetoriais.

-Instalação e Execução
Para configurar o projeto localmente, siga os passos abaixo:

Clonar o repositório :

git clone https://github.com/RossanoCunha23/DDM_LD_-N-1RossanoCunha-.git


Aceder ao diretório do projeto:

cd "projecto itask-Rossano Cunha"


Instalar as dependências:

npm install

Executar a aplicação em modo de desenvolvimento:

npm run dev

Nota: Certifique-se de que possui o Node.js instalado na sua máquina para executar os comandos acima.
